# package-elixir

Elixir/BEAM reference library with OTP-friendly patterns and ExUnit tests.

## Layout

| Path | Holds |
| --- | --- |
| `lib/` | publishable library |
| `test/` | ExUnit tests |
| `docs/` | usage and release notes |

## Build

```bash
mix test
```

## Use

```bash
Add `{:gardusi_kit, path: "../package-elixir"}` or consume a tagged release.
```
